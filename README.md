# 👕 SUMMA Clothes — sitio web

Landing page de **SUMMA Clothes**, mi marca de streetwear y piezas de lujo en CDMX.

- Diseño oscuro con acentos dorados
- Secciones: inicio, producto destacado (Cadillac F1), nosotros, Instagram ([@summa_clothesmx](https://www.instagram.com/summa_clothesmx/)) y contacto
- Un solo archivo `index.html` (HTML + CSS + JavaScript), sin dependencias

## ▶️ Cómo verlo
Abre `index.html` en cualquier navegador.
